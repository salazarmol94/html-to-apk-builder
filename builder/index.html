HTML to APK Builder V6

Motor de compilación preparado para GitHub Actions.

Esta V6 se usa primero para comprobar que GitHub puede generar un APK desde input-web.zip.

Pasos:
  1. Subir el contenido de este proyecto al repositorio.
  2. Ir a Actions.
  3. Ejecutar “Build APK from Web ZIP”.
  4. Descargar el artifact “html-to-apk-debug”.
